\section{Legal, Social, Ethical and Professional Issues \& Considerations}
\label{sec:IssuesAndConsiderations}

\large{\raggedright
There is no intention to collect or process primary personal data during this project. Any public datasets used will be handled in accordance with any license conditions they may have. To ensure scientific rigour, the integrity of such datasets will be validated prior to use. \\
~\\
Statistical analysis will be completed using established methods \cite{RodriguezGrasa26} to ensure that the conclusions drawn from this research are reproducible and consistent with the underlying data. One of the goals of this project is to publish the final results, source code and methodology to a public GitHub repository. This commitment reinforces the need to follow accepted professional standards. If this is done, an open-source license will be obtained, such as \href{https://opensource.org/license/mit}{\color{blue}MIT} or \href{https://www.apache.org/licenses/LICENSE-2.0}{\color{blue} Apache 2.0}, to ensure clear terms of reuse for the wider community.
\par
}
