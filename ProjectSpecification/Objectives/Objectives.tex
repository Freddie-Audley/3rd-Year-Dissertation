\section{Objectives}
\label{sec:Objectives}

\begin{flushleft} % Enforces a ragged-right edge for this section
\large

\subsection*{Research}
\begin{itemize}
    \item Quantum Computing
    \item Quantum Machine Learning
    \item Fourier representation of QML models
    \item Generalisation gap analysis
\end{itemize}

\subsection*{Implementation}
\begin{itemize}
    \item Create a pipeline for the creation, training and evaluation of QML models using PennyLane
    \item Use the pipeline to create QML models for various relevant QML problems, focusing on generating models with Fourier spectra expressing the desired properties
\end{itemize}

\subsection*{Analysis}
\begin{itemize}
    \item Collect data on the performance of the QML models on seen and unseen data
    \item Use the collected data to evaluate the generalisation gap\cite{RodriguezGrasa26}
\end{itemize}

If all of the above are completed, the scope of the project may extend to include considerations of the role of Fourier spectra in classical ML, or rigorous proofs of generalisation bounds from Fourier sparsity.

\end{flushleft}
