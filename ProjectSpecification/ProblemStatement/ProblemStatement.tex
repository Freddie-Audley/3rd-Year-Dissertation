\section{Problem Statement}
\label{sec:ProblemStatement}

\large{\raggedright
While results about how sparsity affects generalisation behaviour are known \cite{Caro21}, we lack numerical explorations of how Fourier sparsity influences generalisation behaviour. In particular, given the current state of the literature, it is possible that the Fourier sparsity-based generalisation bounds proven so far are overly pessimistic\cite{Zhang16, Zhang21, GilFuster24}, or that other properties of the Fourier spectrum may hold more explanatory power for generalisation in QML models. The aim of this project is to create and train various QML models so that experimental data can be obtained, which would be used to analyse how sparsity correlates to the generalisation gap.\\
}
